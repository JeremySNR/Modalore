# Security

This is an experimental local desktop application. Recipes are constrained data; they do not carry executable code. Codex actions run through the installed local harness with explicit approvals when requested. A successful model turn, compilation or gameplay session is not a security review.

Do not post credentials, auth URLs, private prompts, saves or raw Codex logs in public issues. Use GitHub’s private vulnerability reporting when available, or report a non-sensitive request for a private contact route. Include affected versions and a minimal reproduction without private data.

Preview binaries are unsigned. Download only from this repository’s releases and verify the SHA-256 checksum. Hashes verify the downloaded bytes, not the trustworthiness of a recipe’s author. No automatic update service is installed.
