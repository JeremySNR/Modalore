# First game: research and implementation boundary

Research checked 4 November 2026. Terraria with tModLoader is the first target: it has an established mod API and distribution through Steam. [The official usage guide](https://github.com/tModLoader/tModLoader/wiki/Basic-tModLoader-Usage-Guide) covers installing and enabling mods; the [project repository](https://github.com/tModLoader/tModLoader) supports Windows, Linux and macOS. Modalore initially targets Windows only. Steam's manifests across this machine's listed C:, D:, E: and F: libraries did not show either Terraria (105600) or tModLoader (1281930). Manifests are detection hints, not proof of ownership or a working executable.

[ModPlayer documentation](https://docs.tmodloader.net/docs/stable/class_mod_player.html) describes `ModifyHitNPC` for damage dealt by a player to an NPC. The original runtime uses that hook for hostile-target damage and [GlobalNPC.SetDefaults](https://docs.tmodloader.net/docs/stable/class_global_n_p_c.html) for hostile NPC health and coin value; it does not generate C# from recipes. Health has a minimum of one and a maximum of the integer limit; special one-life NPCs are excluded. Scaling velocity every tick compounds, affects jumps and knockback, and varies by AI, so movement is not supported. These mechanics and their hook interactions, including difficulty scaling and unusual enemies, are **not yet compiled or tested in game**. The 'enemies join my army' idea needs additional research and implementation and is not claimed as supported.

The official project reports custom save-directory arguments in [this issue](https://github.com/tModLoader/tModLoader/issues/4110), which also identifies a Host and Play isolation bug. Use single-player only. [ExampleMod](https://github.com/tModLoader/tModLoader/tree/1.4.5/ExampleMod) demonstrates source mods. [Universal Modder's Terraria example](https://github.com/rehan-remade/universal-modder/blob/main/examples/terraria-tmodloader/README.md) documents a command-line build and an isolated output argument; [official source](https://github.com/tModLoader/tModLoader/blob/1.4.5/patches/tModLoader/Terraria/ModLoader/UI/UIModPacks.cs) uses an isolated save directory and `Mods/enabled.json`. The adapter can attempt an isolated build, verify its output hash, checkpoint profile saves, install it and start a game process with isolated directory arguments. This path and version compatibility remain unverified on this machine. Process start is not gameplay evidence.

The [tModLoader repository](https://github.com/tModLoader/tModLoader) identifies its project licence as MIT and also contains terms of use; Terraria itself and other assets have separate rights. Do not bundle Terraria or tModLoader binaries, assets, player saves, or workshop content. Install them through their own channels. Modalore's recipe package contains only validated data, dependency names, attribution hash when supplied, and explicitly limited evidence; its hash detects accidental modification, not identity or authenticity. It neither contains nor executes arbitrary code. Source for our own runtime ships separately and is not copied from the other projects. Check project-specific terms and exact version compatibility before any redistribution.

[Universal Modder](https://github.com/rehan-remade/universal-modder) is MIT-licensed and focuses on agent-directed game reconnaissance and creation across games; its broad execution surface does not fit this initial constrained recipe boundary, so no code was reused. [Nexus Vortex](https://www.nexusmods.com/vortex) presents game-specific mod management and collections. [CurseForge](https://support.curseforge.com/support/solutions/articles/9000196984-installing-minecraft-modpacks) makes discovery and one-click installation central, with profiles/modpacks as familiar concepts. Modalore borrows the user-facing clarity, not their assets or proprietary distribution services.

Remaining work: confirm license terms for intended distribution; build and test the source with a supported installed tModLoader version; verify local launch arguments, profile isolation, per-NPC behavior, coin effects and crashes; add a tested build/install rollback and executable version/dependency checks; test export to another actual installation; implement save copying only as an explicit user-selected operation. Schema validation, package integrity and profile checkpoint tests are not game build, launch, gameplay or security certification.
