Modalore’s first Windows preview: a local mod-recipe studio powered by your installed Codex CLI.

Download **Setup.exe** for an installer or **Portable.exe** to try without installing. Windows x64 only. These preview builds are unsigned; `SHA256SUMS.txt` records the exact download hashes.

Browse original concept recipes, adjust player damage/enemy health/coins, save projects, ask local Codex to revise them, and export/import the exact recipe version. Codex credentials stay managed by Codex. Sliders and recipe sharing do not need an AI account.

**Experimental game integration:** Terraria/tModLoader was not available for gameplay validation. Build, launch, compatibility and in-game save isolation remain unverified. The app explicitly warns before attempting Play. Use new single-player characters/worlds only. Concept illustrations are not game footage.

No hosted publishing, live share links, multiplayer, arbitrary mod code or automatic updates. See README, Getting started and Verification in the repository before using the experimental game path.
